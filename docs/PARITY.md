# FlowJo feature parity review

Status of every FlowJo 10 feature area in FlowDesk. "Same" means the feature
works the way a FlowJo user expects; details and differences are noted.

| Area | FlowJo | FlowDesk | Notes |
|---|---|---|---|
| **Workspace** | Sample/group panes, keyword columns, sort, rename, delete, find, select equivalent | Same | Keyword columns via *Edit Columns…*, editable in place (double-click or F2 on a keyword cell of a sample row; `$` keywords stay read-only); click a column header (Name, #Cells, keyword) to sort the samples, again to reverse (sort indicator, undoable, saved order); *Move Up / Move Down* (Ctrl+Shift+↑/↓); *Find…* (Ctrl+F) box above the tree filters samples, populations and keyword cells and survives refreshes; *Select Equivalent* (Ctrl+E) selects the same population in every sample shown; *Rename Samples…* from a keyword (TUBE NAME, `$SRC` …), find/replace (regex) or prefix/suffix with preview, one undo step; *Name Samples by Keyword…* shows samples under a keyword value (display only; preference `sample_name_keyword`); *Duplicate* (Ctrl+D), *Copy as Text* (Ctrl+Shift+C, tab-separated rows for Excel), *Reveal in Finder / Show in Explorer*, *Copy File Path*, hover tooltips with file and key keywords; sort by keyword in the Experiment band; Delete/Backspace removes selected samples (confirmed); drag a gate onto another population of the same sample to move it (Alt/Option-drag copies), a sample onto another to copy its whole tree, a statistic row to copy that statistic; *Window* menu lists the workspace, graph windows and the Layout/Table/Compensation/Plate editors; new graph windows open inside the screen. Drag-reordering of sample rows and *Duplicate* in the graph window are pending |
| Open / Save | `.wsp` | `.fdw` (JSON) + `.wsp` import/export | FlowJo opens FlowDesk's exports (verified, see README) |
| Loading large workspaces | Background loading with progress bar, size-limited data cache, memory meter | Thread-pool loader filling data and counts with a cancelable status-bar progress, header prefetch for adding hundreds of files, per-workspace memory cap (`memory_limit_mb`) releasing least-recently-used samples not shown in a window, status-bar memory meter | `flowdesk/ui/loader.py` (`install(window)`, `run_with_progress` for other long operations) |
| Templates | `.wspt` save/apply | `.fdwt` save/apply; `.wspt`/`.wsp` can be applied as templates | *File ▸ Save as Template…* / *Apply Template…* or open a template file |
| Groups | Manual, keyword-based (live), roles, group gating, drag to group, one group per keyword value | Same | *Create Groups by Keyword…* (Sample List band) makes one live group per distinct value (`keyword Equals value`, name pattern, optional colours) in one undo step; Compensation group auto-populated from `$FIL`; the current group's bold row heads the sample list with its gating template (mean % of parent / count / statistic over the members; F2 rename, Delete, drag, double-click act on every member); Create/Edit Group sets role (Test / Control / Compensation), style (plain / bold / italic) and *Live* (untick to freeze; also *Workspace ▸ Live Membership*); F2 renames and Delete removes a group in the group pane; FCS files dropped on a group join it; *Edit Keywords…* gives a sample that joins a live group the group's gates; a matrix attached to a group (*Compensation ▸ Apply to group…* or the wizard) is applied to samples that join it later. Test/Control in `.wsp` import/export and italic in `.fdw` are pending |
| Annotate Experiment | Experiment metadata, panel | Same | Experiment band (Workspace tab) |
| Inspect sample | Header/keyword inspector | Same | Also shows the acquisition time and the event rate (events/s) from `$BTIM`/`$ETIM`, or from the Time channel × `$TIMESTEP` once the events are loaded; not yet a table statistic |
| Add keyword / edit keywords | Yes, incl. keyword tables | Same, plus from file-name regex | *Add Keyword…* imports a keyword table (CSV / TSV / Excel `.xlsx`: sample name plus one column per keyword, all columns or one) with a one-column-per-keyword preview, as one undo step; keyword cells of the sample list are editable in place |
| Plate Editor | 96/384-well view, heat-map of a statistic, experiment design | Same | Wells from `$WELLID`/`WELL ID` or the file name; select a row / column by its header, every well by the corner, or drag a rubber band; *Set Keyword on Selected Wells…* and *Fill Series…* (start × factor + step across columns or down rows, or a list) write keywords; samples placed by hand or from a plate map get the `WELL ID` keyword; several plates per workspace (`$PLATEID` / `$PLATENAME` / `PLATE NAME` …) are shown one at a time through the *Plate* selector |
| Cytometer settings | Default scales per cytometer (Preferences ▸ Cytometers, kept across workspaces; instrument list) | Same: scale, width basis, positive and extra negative decades, linear min/max per parameter; "Use in all workspaces" keeps them as application preferences; built-in starting points per instrument family (*Instrument Defaults*) | Cytometry band; a linear time row without maximum ("Auto") follows the acquired data |
| **Graph window** | Pseudocolor/dot/contour/zebra/density/histogram | Same | |
| Gate tools | Rectangle, polygon, ellipse, quadrant, range, bisector, freehand, magnify | Same (zoom = magnify) | Same letter shortcuts |
| Gate editing | Move/resize, rename, delete, tint, lock, NOT gate, copy/paste, apply to group | Same | |
| Axis selection / transform | Axis buttons, `T` dialog (biex width basis, decades), Ctrl+arrows; one transform per raw parameter; auto-ranged time / log-amplified axes; default transform and width basis preferences | Same | Linear / biexponential (logicle) / log / arcsinh. Comp-X always shows X's transform; Time spans the acquired data, `$PnE` channels their decoded decades; `default_transform` / `default_width_basis` apply to new parameters; changing one axis re-gates only display-space gates on it; optional data-driven width basis after compensation (`auto_width_basis`) |
| Ancestry, drill-down by double-click | Yes | Same | |
| Overlays / backgating | Overlay populations, histogram overlays (offset) | Same | Legend drawn on the plot |
| Statistics window | Yes | Same (dock) | |
| Save plot as image / print | PNG/SVG/PDF | Same | |
| **Statistics** | Count, freq., mean, median, geo-mean, mode, SD, CV, robust SD/CV, min, max, percentile | Same set | |
| Boolean gates | AND / OR / NOT | Same | The dialog offers *Add to all samples in “group”* (on by default for a custom group; always on in the group tree) |
| Derived parameters | Ratio, log, sums | Same (ratio/product/sum/difference/log10) | |
| **Compensation** | Matrix editor, apply to group, wizard from controls, AutoSpill, spreading matrix, .mtx | Same | Wizard pages *Controls → Gates → Matrix → Diagnostics*: controls from any group, a population per control (scatter gate picked by default, Events shows the gated count), automatic positive / negative split shown on each control's histogram with draggable / typed positive and negative ranges, per-control diagnostics (positive / negative counts and medians, stain index, warnings for weak or missing positives, whose rows stay uncompensated), method *Median difference* or *AutoSpill* (iterative heteroscedastic Huber regression on the positive events, negative coefficients allowed, convergence and unmixing-residual report), spillover spreading matrix; the controls and gates are remembered for the next run. Editor: Undo / Redo (Ctrl+Z / Ctrl+Shift+Z) in the window, spillover % / compensation (inverse) view, Copy / Paste (tab-separated, spreadsheets), import of FlowJo `.mtx` (XML or text), CSV / TXT and another FCS file's `$SPILLOVER`, export to `.mtx` (XML or text) / CSV, *Control Plots* tab (N×N compensated single-stain controls, red / blue hot-spot frames and grid cells for under- / over-compensation, click selects the cell, wheel ±0.1 %), *Spreading Matrix* tab, *AutoSpill* refinement of any matrix. *Apply to group…* attaches the matrix to the group (`settings["group_matrices"]`): samples that join later, by hand or a live criterion, inherit it. Matrices are matched to channels by `$PnN`, else by `$PnS` stain name; applying to a sample lacking matrix parameters warns and names them, and the sample table marks such matrices as not applicable. Wizard within 1.3 points of FACSDiva on real controls (ARIA III, 3 colours), within 0.3 points of CytExpert on the 7 good controls of an 8-colour CytoFLEX set (the 8th is flagged as weak). Dropping a `.mtx` on the workspace window is pending |
| **Layout Editor** | Drag plots, overlays, text, arrange (align / distribute / size), copy / paste, statistic and keyword text, batch (group / keyword, header, PDF / PowerPoint / image files / printer / new layouts), export PDF / PNG / JPEG / TIFF / SVG / EMF / PowerPoint | Same (no EMF / EPS) | Ribbon (Layout / Arrange / Text / Export) plus menus; *Arrange ▸ Align* (left, centre, right, top, middle, bottom), *Distribute* (horizontal / vertical), *Size* (same width / height / size); Ctrl+Z / Ctrl+Y, Ctrl+X / C / V (objects between layouts, also as an image for PowerPoint / Word), Ctrl+A, Ctrl+D, Ctrl+B / I / U and Ctrl+W work inside the editor window; *Add to Layout* keeps axes, plot type and display options, and the overlays a graph window passes (`add_population(..., overlays=)`); dropping a multi-sample selection or a group population on a plot overlays every sample, *Overlay…* opens a chooser; *Layout Plot Options* re-points sample / population and sets gates / labels, smoothing, dot size, events, contour level, histogram y-axis / line, colour map, background, fonts, overlays and annotations (statistics / keywords listed under the plot); text boxes take bold / italic / underline / colour / alignment / font and tokens (`{$FIL}`, `{Sample}`, `{Median FSC-A}`, `{/Cells \| Freq. of Parent}`) resolved per batch page; a dropped statistic row becomes live text; *Page Setup* has more paper sizes, a custom size, margins and *Use as default*; raster export at 72–600 dpi, *Copy Page as Image*; *Batch…* runs behind a cancellable progress dialog; *Open Graph Window* from a plot. FlowJo layout objects in `.wsp` and panel iteration are not mapped |
| **Table Editor** | Population×statistic columns, keywords, batch over group, CSV | Same | |
| **Tools: dimensionality reduction** | tSNE, UMAP, PCA (plugins) | Same (openTSNE/sklearn, umap-learn, sklearn PCA) | Results become parameters you can gate on; *Project onto Existing…* places further samples on an earlier PCA/FlowSOM/k-means result (model saved with the workspace) or t-SNE (openTSNE)/UMAP result (same session only) |
| Tools: clustering | FlowSOM, Phenograph, X-shift | FlowSOM-style SOM + metaclustering, Phenograph (Jaccard kNN graph + built-in Louvain), k-means | X-shift not included |
| Tools: population comparison | Chi-squared T(x) | Same + KS | |
| Tools: cell cycle | Dean-Jett-Fox, Watson | Same: Dean-Jett-Fox and Watson pragmatic models, optional debris and aggregate (doublet) components | %G1 / %S / %G2M also available as table statistics |
| Tools: proliferation | Division modelling | Same (dye-dilution generations; division, proliferation and expansion index; generation 0 from an undivided control) | Division index, proliferation index and % divided also available as table statistics |
| Tools: kinetics | Statistic vs time | Same | |
| Tools: concatenate / downsample / export | Yes | Concatenate, export population as FCS/CSV | Downsample via "max events per sample" when concatenating |
| Plugins | Java plugin API | Python modules with `install(window)` | See `flowdesk/ui/main_window.py` `EXTENSION_MODULES` |
| Calibration (MESF beads) | Yes | Same: *Calibrate (MESF)…* finds the bead peaks, fits intensity ↔ MESF in log-log space and creates `<param> MESF` parameters | Quality Control band |
| Data cleaning (FlowAI / FlowClean / PeacoQC plugins) | Plugins | *Data Cleaning…*: flow-rate, signal-stability, change-point and dynamic-range checks → a "QC pass" population (flag parameter or time gates), batch over a group | Quality Control band |
| Undo / redo | Gating only | Gating, keywords, sample order and names, computed parameters, compensation matrices, experiment / cytometer / plate settings, layouts and tables | One step per action, grouped for multi-step tools; the Undo/Redo shortcuts work in every window (Layout/Table Editor, Compensation, Plate Editor) |
| Cloud / portal, licensing | FlowJo Portal | Not applicable | |

Platforms: macOS, Windows and Linux (see docs/INSTALL.md); tests run on all
three in CI.
